# سامانه نمایندگان توسن تکنو (PWA)

## مخزن
https://github.com/namdarenbatm-dev/tosan-techno-pwa

## فعال‌سازی GitHub Pages (یک‌بار)
1. برو به: https://github.com/namdarenbatm-dev/tosan-techno-pwa/settings/pages
2. در بخش **Source** گزینه **Deploy from a branch** را انتخاب کن
3. Branch را روی **main** و پوشه را روی **/ (root)** بگذار
4. Save کن
5. بعد از ۱–۲ دقیقه لینک اپ این است:

**https://namdarenbatm-dev.github.io/tosan-techno-pwa/**

## اگر اپ کامل باز نشد
فایل‌های `index.html` و `app.js` را از زیپ نهایی آپلود کن:
1. برو به مخزن → Add file → Upload files
2. دو فایل را بکش و رها کن → Commit

## نصب روی موبایل
- **آیفون:** لینک Pages را در Safari باز کن → Share → Add to Home Screen
- **اندروید:** لینک را در Chrome باز کن → منو → Install app

## لوگو
آیکون صفحه اصلی با برند توسن تکنو (آبی) تنظیم شده است.
