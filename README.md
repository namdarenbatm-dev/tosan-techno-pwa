# سامانه نمایندگان توسن تکنو
## نسخه نهایی PWA — Sales Engineering Edition

---

### نحوه اجرا (بدون هیچ تنظیم اضافه‌ای)

**روش ۱ — با Node (پیشنهادی):**
```bash
npx serve .
```
سپس آدرس نمایش‌داده‌شده را در مرورگر باز کنید.

**روش ۲ — با Python:**
```bash
python3 -m http.server 8080
```
سپس بروید به: http://localhost:8080

**روش ۳ — با PHP:**
```bash
php -S localhost:8080
```

بعد از باز شدن در مرورگر موبایل یا دسکتاپ:
- گزینه **Install / افزودن به صفحه اصلی** را بزنید
- اپ مثل یک اپلیکیشن واقعی نصب می‌شود

> نکته: برای نصب PWA باید روی `localhost` یا دامنه با HTTPS اجرا شود.

### قابلیت‌های نسخه نهایی

| بخش | قابلیت |
|------|--------|
| **داشبورد** | KPIهای فروش، هدف ماهانه، نسبت کشلس، پاداش، اعتبار |
| **فروشگاه** | کاتالوگ + سازنده بسته + دکمه شبیه‌ساز قیمت |
| **موتور قیمت‌گذاری** | شبیه‌ساز + پنل تنظیم قوانین + سطح وفاداری |
| **سبد خرید** | قیمت پویا + جعبه شفافیت تخفیف‌ها |
| **سفارش و فاکتور** | پیگیری کامل وضعیت |
| **کیف پول و اعتبار** | شارژ، برداشت، انتقال، درخواست اعتبار |
| **پاداش و لیگ** | چرخه شفاف + رتبه‌بندی نمایندگان |
| **شبکه معرفی** | لینک + QR + درخت زیرمجموعه |
| **گزارش‌ها** | فروش ماهانه، ترکیب محصول، قیف |
| **پشتیبانی و پروفایل** | تیکتینگ + احراز هویت + حساب بانکی |
